Antes de empezarBefore you start

  1. Haz una copia de seguridad de la tarjeta SD (proyectos, packs y samples) y no trabajes con proyectos importantes mientras pruebas el mod. No se han reportado fallos, pero las versiones están en prueba. Si no quieres arriesgar la SD, elige RC2S.Back up the SD card (projects, packs and samples) and do not work on important projects while you test the mod. No failures have been reported, but the versions are being tested. If you do not want to risk the card, pick RC2S.
  2. Descarga el firmware oficial Circuit Tracks 1.2.1 (build 4486) desde Novation: circuittracks-firmware-4486.syx (descarga directa de Novation Components: el navegador guarda el .syx, 432 961 bytes). Novation Components: components.novationmusic.com.Download the official Circuit Tracks 1.2.1 (build 4486) firmware from Novation: circuittracks-firmware-4486.syx (Novation Components’ direct download: the browser saves the .syx, 432,961 bytes). Novation Components: components.novationmusic.com.
  3. Cierra Novation Components y cualquier DAW o programa MIDI (en Windows, un puerto MIDI solo lo puede abrir una aplicación).Close Novation Components and any DAW or MIDI program (on Windows a MIDI port can only be opened by one application).
  4. Conecta el Circuit Tracks por USB y enciéndelo de forma normal (o en modo bootloader: Scales + Preset + Note al encender). No lo desconectes durante el envío.Connect the Circuit Tracks over USB and power it on normally (or in bootloader mode: Scales + Preset + Note at power-on). Do not disconnect it while sending.
  5. Usa Chrome o Edge (Web MIDI con SysEx).Use Chrome or Edge (Web MIDI with SysEx).
