# Alpha 7.40 — qué probar

Instalar `circuittracks-4486-A7.40.syx` (modo bootloader: Scales + Preset + Note al encender). Es la Alpha 7.39 + un arreglo del morph.

1. **Morph de Synth 1 / 2 con el LFO (K2 / K3)** entre dos patches con osciladores distintos: el ruido / aliasing de la 7.39 debería desaparecer o bajar mucho (los osciladores se actualizan en cada fotograma, no cada pocos).
2. Lo mismo con la envolvente (pads 1 / 8).
3. Escucha si el tempo se arrastra con muchas notas sonando durante el morph (son hasta 18 escrituras más por fotograma).
4. Todo lo de la 7.39 sigue igual (Octave con el morph, páginas de sección, Macros 2…).
