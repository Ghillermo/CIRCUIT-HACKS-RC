# Example patches of the own synth (MIDI 1 / 2)

Made by `tools/make_examples.py`. Upload them with the card app (`tools/sd_app.html`: **Custom patches → Upload .ctm**) into free slots of a pack, then load them from the MIDI 1 / 2 Preset view (pads 9-24, Octave for the pages). Each one sets its engine, its values and the destinations of **page 4** (the 8 sequenceable knobs, the ones you can record) and of **Shift + pad 4** (8 non-sequenceable knobs): the knobs worth turning for that sound. The firmware needs Beta 5.42 or later for the FM instruments' destinations to change when you load one from the pad 8 list; the files work on any build with the own synth's patches (the parts a build does not know are ignored).
